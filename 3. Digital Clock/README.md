# Digital Clock

A simple **Digital Clock** application built using **Python and Tkinter**. The application displays the current time, AM/PM, and date in a graphical window. The clock automatically updates every second.

## Features

* Displays the current time
* Displays AM/PM
* Displays the current date
* Automatically updates every second
* Simple graphical user interface
* Customizable font and colors
* Built using Python

## Technologies Used

* **Python 3**
* **Tkinter** for the graphical user interface
* **time module** for retrieving the current time and date

## Requirements

Before running the project, make sure Python 3 is installed on your system.

Check your Python version:

```bash
python3 --version
```

### Tkinter

Tkinter is included with most Python installations.

If Tkinter is not available on your system, install the appropriate Tkinter package for your operating system.
